# Design data

Generated by the Figma skills. Commit these files; they are the machine-readable
side of `blueprint/context/figma.md`.

| File | Written by | Read by |
| --- | --- | --- |
| `tokens.json` | `/figma` (`figma-extract.mjs tokens`) | `tokens-to-css.mjs`, `/section`, `/design-sync` |
| `map.json` | `/figma` (sections), `/section` (elements) | `pixel-check.mjs`, `/section`, `/assets` |
| `snapshot.json` | `/figma`, `/design-sync` after approval | `/design-sync` |

Edit `tokens.json` only through `/figma`, `/design-sync`, or an approved spec,
then run `node blueprint/scripts/tokens-to-css.mjs` to regenerate `app/globals.css`.
